07 — Proyectos

Proyectos

Plataforma en USA

Plataforma desarrollada para el mercado estadounidense, con integración personalizada de una pasarela de pago y generación automatizada de PDFs personalizados para cada cliente. Posteriormente, el proyecto evolucionó hacia una implementación basada en WordPress y WooCommerce.

Central en casa

E-commerce headless desarrollado desde cero, con un frontend construido en Next.js y Shopify como backend y plataforma de gestión comercial. La solución fue desplegada y alojada en AWS, cubriendo de forma integral el desarrollo y la implementación del proyecto.

Deliver Mexico

Plataforma de logística de última milla desarrollada con Next.js, diseñada para integrarse fácilmente con negocios que utilizan Shopify y requieren soluciones de entrega. Incluye una API basada en GraphQL para gestionar la comunicación e integración entre las diferentes plataformas y servicios.

Banorte AFORE XXI

Plataforma personalizable desarrollada principalmente con PHP y jQuery, diseñada para adaptarse a diferentes necesidades y contenidos. Posteriormente, el proyecto evolucionó hacia una arquitectura basada en WordPress como backend para facilitar su administración y mantenimiento.

Smart Bamboo

Implementación de soluciones tecnológicas para una tienda Shopify Plus, incluyendo el desarrollo de APIs para facilitar el acceso y análisis de datos por parte del equipo de Data Science. Se desarrollaron experiencias personalizadas para los usuarios, optimizaciones avanzadas del tema y aplicaciones custom para ampliar las funcionalidades de la plataforma.

Palmers

Desarrollo y mantenimiento de la tienda Shopify, implementando estrategias de personalización y marketing basadas en datos. Se desarrollaron descuentos inteligentes, recomendaciones de regalos según el historial de compra, predicción de próximas compras, segmentaciones avanzadas, flows personalizados y un sistema de loyalty adaptado al comportamiento de cada cliente.

CreamRight

Desarrollo de experiencias Shopify desde cero con Liquid, creación de apps para extender funcionalidades clave, personalización del checkout y desarrollo de Theme App Extensions. También se implementaron mejoras y funcionalidades avanzadas para potenciar las capacidades B2B de la plataforma.

Shopify LLM

Integración de Shopify con diferentes LLMs para analizar e interpretar el catálogo, generando títulos, descripciones, tags y atributos optimizados. También se utilizan para detectar productos relacionados, oportunidades de cross-selling, crear recomendaciones y generar estrategias de merchandising basadas en los datos de la tienda.
